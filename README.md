# DJ Ñanky — Web

Landing de alto impacto visual para **DJ Ñanky** (estructura tipo [rizzet.cl](https://rizzet.cl/), morph de color al hacer scroll).

## Local

```bash
fnm use 22   # Node >= 22.23.4
npm install
npm run dev
```

Con `base: /dj_web_pinky` la URL local es `http://localhost:4321/dj_web_pinky/`.

## Deploy

Push a `main` → GitHub Actions → GitHub Pages.

URL: https://felipebarraza6.github.io/dj_web_pinky/

## Contenido

Edita `src/data/dj.ts` (copy, WhatsApp, email, galería). Media en `public/media/`.
